HOW TO USE
----------
1. Run ONE task at a time: copy the PROMPT> line into Claude Code, wait for it
   to finish, commit + push yourself, and check GitHub Actions.
2. If CI goes red: paste the failing log with the words "fix ci" — fix it
   before starting the next task.
3. Standing policy (already active): Claude writes code + tests ONLY. Nothing
   builds/runs/installs locally; GitHub Actions verifies everything.
4. Gates between phases are real: do not start the next phase until the gate
   line is demonstrably true.
